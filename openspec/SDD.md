# 禮券退貨彙整平台 - 系統技術規格書（SDD）

版本 1.0　2026-07-31

## 1. 功能描述

本系統處理大量零散序號禮券的退貨作業，取代人工目視判斷連號（耗時且易錯）。提供兩種工作模式：

- **批次模式**：一次貼入大量序號，系統輸出整理好的連號群組報表（含統計與錯誤清單）。
- **即時歸組模式**：逐張刷入（條碼槍或手動輸入），邊刷邊即時分配到正確群組，支援容忍值調整。

操作流程：使用者登入 → 選擇模式 → 輸入/刷入序號 → 系統解析並分組 → 檢視群組結果 → 匯出 TSV 供後續退貨作業使用。

## 3. 序號格式規範

範例：`E030026000008001-5`

| 欄位 | 範例值 | 說明 |
|---|---|---|
| 券種 | `E` | 1 碼英文字母，識別券種類型 |
| 批號 | `03002600` | 不固定位數數字，識別發行批次 |
| 流水號 | `0008001` | 固定 7 碼數字，連號比對依據 |
| 檢查碼 | `5` | 連字號後 1 碼數字，格式驗證用 |

Regex：`^([A-Z])(\d+?)(\d{7})-(\d)$`（Group2 懶惰匹配，讓 Group3 固定 7 碼優先對齊）

連號判斷規則：相同「前綴」（券種 + 批號）下，流水號整數值連續（n, n+1, n+2…）即為同一組。

## 4. 自動計算邏輯表

| 計算項目 | 公式 / 邏輯 | 驗收範例 |
|---|---|---|
| 前綴 (prefix) | `type + batchNo` | `E` + `030026000` → `E030026000` |
| 連號分組 (groupSerials) | 依 prefix 分桶 → seq 升冪排序 → 線性掃描 `seq[i] === seq[i-1]+1` 則延續，否則切割新區段 | 輸入 8001,8002,8003,8010,8020 → 輸出 3 組：(8001~8003,3張)、(8010~8010,1張)、(8020~8020,1張) |
| 即時歸組距離 (findBestGroup) | 對候選群組每個 item 計算 `dist = |item.seq - parsed.seq|`，取最小值；`dist ≤ tolerance` 才可併入，多組合格時取距離最小者 | 群組含 8001，容忍值 20，刷入 8010 → 距離 9 ≤ 20 → 併入 |
| 容忍值預設 | 20，可即時調整（1~200），僅影響後續刷入判斷，不影響已建立群組 | — |

## 5. 邊界情況

- 全形字元/空白：`parseSerial` 前置 `NFKC` normalize + 去空白處理。
- 流水號長度非 7 碼：目前 regex 固定 7 碼；如需彈性可改為 `\d{5,8}`（本版未實作，列入未來擴充）。
- 容忍值為 0：只合併嚴格相鄰（dist === 0），等同無容忍模式。
- 重複序號：以 `raw` 字串為鍵記錄於 `seen` 集合，重複則略過並提示，不計入統計。

## 6. 驗收標準

1. 貼入本規格書第 10 節測試序號，批次模式應輸出：9 筆輸入、7 筆有效、4 個群組、1 筆重複、1 筆格式錯誤。
2. 即時歸組模式下，容忍值 20 時序號 `8010` 應併入含 `8001` 的群組（距離 9）；重複序號應顯示「↩ 重複略過」且不計入統計。
3. 匯出 TSV 需可直接貼入 Excel，欄位為：前綴、起始流水號、結束流水號、張數。
